## Usage Examples

### Light Mode
```
Body:           White background, dark slate text
Cards:          Slate-50 background, slate-900 text
Buttons:        Slate-900 bg / Emerald-500 bg
Borders:        Slate-200
Shadows:        Subtle, light
```

### Dark Mode
```
Body:           Slate-900 background, white text
Cards:          Slate-800 background, white text
Buttons:        Emerald-500 bg / Slate-800 bg
Borders:        Slate-700
Shadows:        Deeper, stronger
```

## Component Examples

### Hero Section
```
Light Mode:
  - White background
  - Slate-900 heading
  - Emerald-600 to Teal-500 gradient on name
  - Slate-600 for body text

Dark Mode:
  - Slate-900 background
  - White heading
  - Emerald-400 to Teal-300 gradient on name
  - Slate-300 for body text
```

### Navigation Header
```
Light Mode:
  - Transparent → White/95 (on scroll)
  - Slate-600 nav links
  - Slate-100 theme button background
  - Slate-900 CTA button

Dark Mode:
  - Transparent → Slate-900/95 (on scroll)
  - Slate-300 nav links
  - Slate-800 theme button background
  - Emerald-500 CTA button
```

### Footer
```
Light Mode:
  - Slate-50 background
  - White bottom section
  - Slate-200 borders
  - Slate-900 CTA button

Dark Mode:
  - Slate-900 background
  - Slate-950 bottom section
  - Slate-800 borders
  - Emerald-500 CTA button
```

## Quick Test Checklist

✅ Toggle theme and verify:
  - Text remains readable
  - Buttons have proper contrast
  - Borders are visible
  - Shadows are appropriate
  - Gradients look good
  - Hover states work
  - Transitions are smooth (400ms)
